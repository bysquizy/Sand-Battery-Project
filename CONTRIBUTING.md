# Contributing

Sand Battery Studio is a three-person ESE101 academic research project. Please keep all project artifacts and code comments in **English**.

1. Open an issue describing the proposed engineering or interface change.
2. Create a short-lived feature branch and use a pull request for review.
3. Explain units, equation boundaries, uncertainty and research provenance for numerical modifications.
4. Run `python -m pytest -q` and `python -m compileall -q streamlit_app.py visuals.py engine` before submitting.
5. Record any material changes to numerical results or input assumptions.
6. Keep dependencies lightweight. Do not add AI APIs, heavy frameworks or unvalidated materials without a documented reason.
7. Comply with course integrity rules, including disclosure of any instructor-authorized AI assistance.

The repository has no general open-source reuse license yet. External contributions and licensing should be agreed by the student team.
