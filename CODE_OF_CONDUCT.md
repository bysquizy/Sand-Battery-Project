# Code of Conduct

This is an academic student project. All participants are expected to communicate respectfully, discuss technical claims in good faith, credit sources and contributors, and avoid discriminatory or harassing behavior.

Use GitHub Issues or Pull Requests for ordinary technical reports and constructive feedback. Do not publish passwords, private student information or exploit details. For security-sensitive reports, consult [SECURITY.md](.github/SECURITY.md).

The student maintainers may moderate contributions that violate these principles on a best-effort basis; no formal institutional disciplinary process is implied. The project is **not** an official IZTECH service.
